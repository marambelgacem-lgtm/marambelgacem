# Images

`favicon.svg` is the warm amber lowercase “r” browser-tab icon for rouma.

The website background is a CSS grid, so no background photograph is needed. Its size, line opacity, and movement are controlled in `css/style.css`.

You can place future project or article images in this folder. From the homepage, use a relative path such as `images/your-file.jpg`. From an article inside `writeups/`, use `../images/your-file.jpg`.
